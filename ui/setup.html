Vigie

Configuration — quel est le rôle de ce PC ?
Important : un seul de vos deux PC doit être l'hôte. Les caméras Wyze n'acceptent qu'un nombre limité de connexions simultanées — installer l'hôte deux fois rendrait les flux instables. L'autre PC se connecte simplement à l'hôte.

PC hôte

Ce PC se connecte aux caméras, gère les enregistrements et partage le dashboard sur le réseau. Choisis le PC qui reste allumé le plus souvent. Docker Desktop est requis sur ce PC.

PC secondaire

Ce PC se connecte au dashboard de l'hôte pour voir les caméras et recevoir les alertes de mouvement. Aucune installation supplémentaire requise.
